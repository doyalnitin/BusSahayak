Offline Voice Assistant — VOSK + Gemma + Piper

100% Local | No API Keys | No Internet Required After Setup

VOSK (STT) Gemma via Ollama (LLM) Piper (TTS) Hindi + English

1. Architecture Diagram
MIC
User speaks
VOSK
Speech → Text
GEMMA (Ollama)
Think + Reply
PIPER
Text → Speech
SPEAKER
Audio plays

How It Works:

Data Flow:
1. User speaks into microphone
2. VOSK converts speech → text (offline STT)
3. Text sent to Gemma via Ollama API (localhost:11434)
4. Gemma generates text response
5. Piper converts text → audio (offline TTS)
6. Audio plays through speaker
Key Points:
• 100% offline — no internet needed after setup
• No API keys — Gemma runs locally via Ollama
• Hindi + English — both languages supported
• Fast — typical response < 3 seconds
• Customizable — swap models, add wake words
2. What Each Tool Does
VOSK — Speech to Text (STT)

What: Offline speech recognition engine. Converts spoken words into text without internet.

How: Uses pre-trained Kaldi models. Supports 20+ languages including Hindi, English, Hinglish.

Specs:

  • Model sizes: 40MB (small) to 1.5GB (large)
  • Real-time streaming recognition
  • 16kHz PCM audio input
  • Word-level timestamps
  • Speaker diarization support
Why VOSK: Lightweight, runs on Raspberry Pi, fully offline, Apache 2.0 license
Gemma — Large Language Model (LLM)

What: Google's open-source LLM. Understands context, generates intelligent responses. Runs locally via Ollama.

How: Ollama loads the model into RAM. Python sends text via REST API (localhost:11434).

Specs:

  • Size options: 2B, 7B, 27B parameters
  • 2B model: ~1.7GB RAM, fast responses
  • 7B model: ~5GB RAM, better quality
  • 27B model: ~17GB RAM, best quality
  • Supports Hindi + English fluently
Why Gemma: Open weights, runs via Ollama, great Hindi support, Apache 2.0
Piper — Text to Speech (TTS)

What: Fast neural text-to-speech engine by Rhasspy. Converts text responses into natural-sounding speech.

How: Uses ONNX neural models. Takes text, outputs WAV audio file. Plays through speaker.

Specs:

  • Model sizes: 15MB to 60MB
  • Real-time synthesis (faster than real-time)
  • Natural sounding voices
  • 40+ languages supported
  • Custom voice training possible
Why Piper: Tiny models, fast synthesis, sounds natural, MIT license

5. Full Working Python Code — assistant.py
assistant.py — Complete Offline Voice Assistant 
#!/usr/bin/env python3
"""
BusSahayak Offline Voice Assistant
Uses: VOSK (STT) + Gemma via Ollama (LLM) + Piper (TTS)
"""

import json
import wave
import os
import sys
import subprocess
import tempfile
import requests
import sounddevice as sd
import numpy as np
from vosk import Model, KaldiRecognizer

# ============================================
# CONFIGURATION
# ============================================
OLLAMA_URL = "http://localhost:11434"
OLLAMA_MODEL = "gemma2"          # or "gemma2:2b" for lightweight
VOSK_MODEL_PATH = "vosk-model-small-hi-0.22"  # Hindi small model
PIPER_MODEL = "hi_IN-swara-medium.onnx"      # Hindi TTS voice
PIPER_EN_MODEL = "en_US-lessac-medium.onnx"  # English TTS voice
SAMPLE_RATE = 16000
WAKE_WORD = "hey bus"            # Wake word to activate
CHANNELS = 1

# System prompt for Gemma
SYSTEM_PROMPT = """You are BusSahayak, a friendly voice assistant for bus booking.
Speak in the same language the user speaks (Hindi, English, or Hinglish).
Keep responses short and conversational (2-3 sentences max).
If user asks about buses, help them search, compare, and book.
Always be polite and helpful. Use simple words."""


# ============================================
# VOSK: Speech to Text
# ============================================
class SpeechToText:
    def __init__(self, model_path):
        print(f"Loading VOSK model from {model_path}...")
        if not os.path.exists(model_path):
            print(f"ERROR: Model not found at {model_path}")
            print("Download it first! See Section 4 in the guide.")
            sys.exit(1)
        self.model = Model(model_path)
        self.recognizer = KaldiRecognizer(self.model, SAMPLE_RATE)
        self.recognizer.SetWords(True)
        print("VOSK model loaded successfully!")

    def listen(self, timeout=10):
        """Listen to microphone and return recognized text."""
        print("\n🎤 Listening... Speak now!")
        try:
            audio = sd.rec(
                int(timeout * SAMPLE_RATE),
                samplerate=SAMPLE_RATE,
                channels=CHANNELS,
                dtype="int16"
            )
            sd.wait()
            # Convert to bytes for VOSK
            audio_bytes = audio.tobytes()

            if self.recognizer.AcceptWaveform(audio_bytes):
                result = json.loads(self.recognizer.Result())
                text = result.get("text", "")
            else:
                result = json.loads(self.recognizer.FinalResult())
                text = result.get("text", "")

            if text:
                print(f"📝 You said: {text}")
            else:
                print("No speech detected. Try again.")
            return text

        except Exception as e:
            print(f"Microphone error: {e}")
            return ""


# ============================================
# GEMMA via OLLAMA: Text to Text (LLM)
# ============================================
class LLMBrain:
    def __init__(self, model_name, ollama_url):
        self.model = model_name
        self.url = ollama_url
        self.conversation_history = []

    def think(self, user_text):
        """Send text to Gemma via Ollama and get response."""
        print("🧠 Gemma is thinking...")

        # Build messages with conversation history
        messages = [
            {"role": "system", "content": SYSTEM_PROMPT}
        ]
        # Add last 5 messages for context
        messages.extend(self.conversation_history[-5:])
        messages.append({"role": "user", "content": user_text})

        try:
            response = requests.post(
                f"{self.url}/api/chat",
                json={
                    "model": self.model,
                    "messages": messages,
                    "stream": False
                },
                timeout=30
            )
            response.raise_for_status()
            result = response.json()
            reply = result["message"]["content"]

            # Store in conversation history
            self.conversation_history.append(
                {"role": "user", "content": user_text}
            )
            self.conversation_history.append(
                {"role": "assistant", "content": reply}
            )

            print(f"💬 Gemma says: {reply}")
            return reply

        except requests.ConnectionError:
            return "Ollama server not running. Start it with: ollama serve"
        except Exception as e:
            return f"Error contacting Gemma: {e}"


# ============================================
# PIPER: Text to Speech
# ============================================
class TextToSpeech:
    def __init__(self, hindi_model, english_model):
        self.hindi_model = hindi_model
        self.english_model = english_model

    def speak(self, text):
        """Convert text to speech and play it."""
        if not text:
            return

        print("🔊 Piper is speaking...")

        # Detect language (simple heuristic)
        has_hindi = any('\u0900' <= c <= '\u097f' for c in text)
        model = self.hindi_model if has_hindi else self.english_model

        with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as f:
            temp_path = f.name

        try:
            # Run Piper TTS
            process = subprocess.Popen(
                ["piper", "--model", model, "--output_file", temp_path],
                stdin=subprocess.PIPE,
                stdout=subprocess.PIPE,
                stderr=subprocess.PIPE
            )
            process.communicate(input=text.encode("utf-8"))

            if process.returncode == 0 and os.path.exists(temp_path):
                # Play the audio
                if sys.platform == "darwin":  # macOS
                    subprocess.run(["afplay", temp_path])
                elif sys.platform == "linux":
                    subprocess.run(["aplay", temp_path])
                else:  # Windows
                    os.startfile(temp_path)
            else:
                print("Piper TTS failed. Check model path.")

        except FileNotFoundError:
            print("Piper not found. Install it first! See Section 4.")
        except Exception as e:
            print(f"TTS Error: {e}")
        finally:
            if os.path.exists(temp_path):
                os.unlink(temp_path)


# ============================================
# MAIN ASSISTANT LOOP
# ============================================
def detect_wake_word(text):
    """Check if wake word is in the text."""
    return WAKE_WORD.lower() in text.lower()


def main():
    print("=" * 50)
    print("  BusSahayak Offline Voice Assistant")
    print("  VOSK + Gemma + Piper")
    print("=" * 50)

    # Initialize components
    stt = SpeechToText(VOSK_MODEL_PATH)
    llm = LLMBrain(OLLAMA_MODEL, OLLAMA_URL)
    tts = TextToSpeech(PIPER_MODEL, PIPER_EN_MODEL)

    print(f"\nSay '{WAKE_WORD}' to activate, or press Enter to talk.")
    print("Type 'quit' to exit.\n")

    while True:
        try:
            # Option 1: Wait for wake word
            # Option 2: Press Enter to talk
            user_input = input("\n[Press Enter to talk, or type message]: ")

            if user_input.lower() == "quit":
                print("Goodbye! 👋")
                tts.speak("Alvida! BusSahayak band ho raha hai.")
                break

            if user_input.strip():
                # User typed a message
                user_text = user_input
            else:
                # Listen to microphone
                user_text = stt.listen(timeout=8)

                if not user_text:
                    continue

                # Check for wake word
                if not detect_wake_word(user_text):
                    print(f"Say '{WAKE_WORD}' first, or press Enter and type.")
                    continue

                # Remove wake word from text
                user_text = user_text.replace(WAKE_WORD, "").strip()

            if not user_text:
                print("No input detected. Try again.")
                continue

            # Get LLM response
            response = llm.think(user_text)

            # Speak the response
            tts.speak(response)

        except KeyboardInterrupt:
            print("\nInterrupted. Goodbye!")
            break
        except Exception as e:
            print(f"Error: {e}")
            continue


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Quick test script to verify all 3 components work."""

import sys
import json
import requests
import subprocess
import tempfile
import os

def test_vosk():
    """Test VOSK speech recognition."""
    print("=" * 40)
    print("1. Testing VOSK (Speech-to-Text)...")
    try:
        from vosk import Model, KaldiRecognizer
        import sounddevice as sd
        import numpy as np

        # Check if model exists
        model_path = "vosk-model-small-hi-0.22"
        if not os.path.exists(model_path):
            model_path = "vosk-model-small-en-us-0.15"
        if not os.path.exists(model_path):
            print("   [SKIP] No VOSK model found. Download one first.")
            return True

        model = Model(model_path)
        rec = KaldiRecognizer(model, 16000)
        print("   [OK] VOSK model loaded!")

        # Quick mic test
        print("   Recording 3 seconds of audio...")
        audio = sd.rec(3 * 16000, samplerate=16000, channels=1, dtype="int16")
        sd.wait()
        if rec.AcceptWaveform(audio.tobytes()):
            result = json.loads(rec.Result())
            print(f"   [OK] Recognized: {result.get('text', '(silence)')}")
        else:
            result = json.loads(rec.FinalResult())
            print(f"   [OK] Recognized: {result.get('text', '(silence)')}")
        return True
    except Exception as e:
        print(f"   [FAIL] {e}")
        return False


def test_ollama():
    """Test Ollama + Gemma LLM."""
    print("\n" + "=" * 40)
    print("2. Testing Ollama + Gemma (LLM)...")
    try:
        # Check if Ollama is running
        response = requests.get("http://localhost:11434/api/tags", timeout=5)
        models = response.json().get("models", [])
        print(f"   [OK] Ollama running! Found {len(models)} model(s).")

        if not models:
            print("   [WARN] No models pulled. Run: ollama pull gemma2")
            return True

        # Test generation
        print("   Testing Gemma response...")
        gen_response = requests.post(
            "http://localhost:11434/api/generate",
            json={
                "model": models[0]["name"],
                "prompt": "Say hello in one word.",
                "stream": False
            },
            timeout=30
        )
        reply = gen_response.json().get("response", "")
        print(f"   [OK] Gemma replied: {reply[:80]}...")
        return True
    except requests.ConnectionError:
        print("   [FAIL] Ollama not running. Start with: ollama serve")
        return False
    except Exception as e:
        print(f"   [FAIL] {e}")
        return False


def test_piper():
    """Test Piper text-to-speech."""
    print("\n" + "=" * 40)
    print("3. Testing Piper (Text-to-Speech)...")
    try:
        # Check if piper is installed
        result = subprocess.run(
            ["piper", "--help"],
            capture_output=True, timeout=5
        )
        print("   [OK] Piper is installed!")

        # Check if model exists
        model = "en_US-lessac-medium.onnx"
        if not os.path.exists(model):
            model = "hi_IN-swara-medium.onnx"
        if not os.path.exists(model):
            print("   [WARN] No Piper model found. Download one first.")
            return True

        # Test TTS
        print("   Testing speech synthesis...")
        with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as f:
            temp_path = f.name

        proc = subprocess.Popen(
            ["piper", "--model", model, "--output_file", temp_path],
            stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.PIPE
        )
        proc.communicate(input=b"Hello, this is a test!")

        if os.path.exists(temp_path) and os.path.getsize(temp_path) > 0:
            size_kb = os.path.getsize(temp_path) / 1024
            print(f"   [OK] Generated audio: {size_kb:.1f} KB")
        else:
            print("   [FAIL] Piper produced empty output")
            return False

        os.unlink(temp_path)
        return True
    except FileNotFoundError:
        print("   [FAIL] Piper not found. Install it first.")
        return False
    except Exception as e:
        print(f"   [FAIL] {e}")
        return False


def main():
    print("BusSahayak - Component Test")
    print("=" * 40)

    results = {
        "VOSK": test_vosk(),
        "Ollama+Gemma": test_ollama(),
        "Piper": test_piper()
    }

    print("\n" + "=" * 40)
    print("RESULTS:")
    for name, ok in results.items():
        status = "[OK]" if ok else "[FAIL]"
        color = "\033[92m" if ok else "\033[91m"
        print(f"  {color}{status} {name}\033[0m")

    all_ok = all(results.values())
    if all_ok:
        print("\nAll components ready! Run: python3 assistant.py")
    else:
        print("\nSome components failed. Fix the issues above.")

    return 0 if all_ok else 1


if __name__ == "__main__":
    sys.exit(main())

One-time setup (5 minutes):

# 1. Install everything
brew install portaudio ollama piper-tts  # macOS
pip3 install vosk sounddevice requests numpy

# 2. Pull models
ollama pull gemma2:2b
wget https://alphacephei.com/vosk/models/vosk-model-small-hi-0.22.zip
unzip vosk-model-small-hi-0.22.zip

# 3. Download Piper voice
wget https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/lessac/medium/en_US-lessac-medium.onnx
wget https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/lessac/medium/en_US-lessac-medium.onnx.json

Each time you use it:

# 1. Start Ollama (if not running)
ollama serve

# 2. Run the test
python3 test_all.py

# 3. Run the assistant
python3 assistant.py

# 4. Press Enter, speak, get response!
# Type 'quit' to exit

Total disk needed:

# Minimum (2B model): ~3 GB
# Recommended (7B):   ~7 GB
# Full (27B):         ~19 GB
