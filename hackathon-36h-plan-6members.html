3. VOICE ENGINE - Build This First
3-Layer Architecture Diagram
USER SPEAKS
"Mumbai se Delhi"
->
STT
Vosk 50ms
->
LLM
Gemma 2B 150ms
->
TTS
Piper 50ms
->
RESPONSE
"3 bus mil gaye"
TOTAL LATENCY: 250ms (Target: under 500ms)
STT - Speech to Text
Primary: Web Speech API (browser)
Fallback: Vosk (offline, 50MB)
Format: 16kHz PCM audio
Languages: Hindi + English
Latency: 50-200ms

Code:
recognition.lang = "hi-IN"
recognition.continuous = false
50ms
LLM - Understanding
Primary: Regex classifier (instant)
Fallback: Gemma 2B Q4 (150ms)
Patterns:
/Mumbai.*Delhi/ = city pair
/kal|parson/ = date
/AC|sleeper/ = bus type
Latency: 5-150ms
150ms
TTS - Text to Speech
Primary: Web Speech Synthesis
Fallback: Piper (offline, 50MB)
Format: 24kHz audio output
Voice: Hindi female
Latency: 50-200ms

Code:
utterance.lang = "hi-IN"
speechSynthesis.speak(u)
50ms
Voice Hooks - Complete Code
// hooks/useVoiceInput.ts - Speech Recognition export function useVoiceInput() { const [isListening, setIsListening] = useState(false); const [transcript, setTranscript] = useState(''); const startListening = () => { const SR = window.SpeechRecognition || window.webkitSpeechRecognition; const r = new SR(); r.lang = 'hi-IN'; r.continuous = false; r.interimResults = true; r.onstart = () => setIsListening(true); r.onresult = (e) => setTranscript(e.results[0][0].transcript); r.onend = () => setIsListening(false); r.start(); }; return { isListening, transcript, startListening }; } // hooks/useVoiceOutput.ts - Speech Synthesis export function useVoiceOutput() { const speak = (text, lang='hi-IN') => { const u = new SpeechSynthesisUtterance(text); u.lang = lang; u.rate = 1.0; window.speechSynthesis.speak(u); }; return { speak }; }
