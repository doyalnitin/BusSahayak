3 Operating Modes (From Presentation)
MODE 1
Voice Only
For: Completely Blind Users
Touch: LOCKED (no touch needed)
Input: Hold MIC -> Speak only
Audio: 24kHz Native PCM
Feedback: Voice + Haptics

Flow:
Hold MIC -> "Mumbai se Delhi" -> Release -> Gemini responds -> Hold again -> "Number 1 book karo" -> Done
MODE 2
Dynamic Switch
For: Low Vision Users
Starts: Locked (like Mode 1)
Unlocks: Via voice command
Visual: Large picture buttons

Flow:
Starts locked -> User says " unlock" -> Touch unlocks -> Can use big buttons OR voice -> Toggle anytime
MODE 3
Dual Combined
For: Voice + Touch Together
Tap: Triggers TTS readout
Hold: Triggers MIC input
Always: Active visuals

Flow:
Tap bus card -> "VRL Travels, 800 rupaye" -> Hold MIC -> "Book karo" -> Done

2. GEMINI LIVE API - Voice Engine + LLM (One Model)
Why Gemini Live API is Perfect for BusSahayak
What Gemini Does (All-in-One)
1. STT (Speech to Text)
Understands Hindi, English, Hinglish natively
No separate STT model needed

2. LLM (Language Understanding)
Extracts cities, dates, preferences from speech
Understands context, emotion, tone

3. TTS (Text to Speech)
Generates natural Hindi audio response
No separate TTS model needed

4. Function Calling
Auto-calls ZuelPay API for bus search
Auto-books tickets via function calls
Key Advantages
Barge-In: User can interrupt anytime
"Sorry ruko, Delhi nahi, Jaipur jana hai"

Multi-Turn Memory: Remembers context
"Ussi bus mein do seat de do" (remembers which bus)

29 Languages: Hindi + English + Hinglish
No language switching needed

Streaming: Response starts playing instantly
User hears first sentence while rest generates

Latency: 300-500ms total
Well under 500ms target
Architecture - Simple 3-Layer
React Native App
Hold MIC -> Record Audio -> Stream
v
Google Gemini Multimodal Live API
WebSocket | STT + LLM + TTS | Function Calling
v
ZuelPay API
Search | Seats | Book
FastAPI Backend
Auth | Data | Redis
PostgreSQL + Redis
Bookings | Seat Locks

5. GEMINI SYSTEM PROMPT - The Brain
Complete System Prompt for BusSahayak
# system_prompt.txt - Give this to Gemini You are BusSahayak, a voice-first bus booking assistant for blind and visually impaired users in India. You speak like a helpful Indian friend. PERSONALITY: - Speak in Hindi-English mix (Hinglish) naturally - Be warm, patient, and encouraging - Use simple words a blind person understands - Never say "dekh lo" or "click karo" - always use voice - Confirm every important action before proceeding - Read out numbered lists for options FLOW: 1. User holds mic and says where they want to go 2. You extract: source city, destination, date, bus preference 3. Call search_buses function 4. Read out results as numbered list: "Pehla bus..., Doosra bus..." 5. Ask: "Kaunsa chahiye? Number bolo." 6. User says number -> call get_seats 7. Read available seats: "Window seat W3 available hai" 8. Ask for passenger name and phone 9. Confirm: "Rahul Kumar, Mumbai se Delhi, kal, VRL Travels. Book karoon?" 10. User says "haan" -> call create_booking 11. Confirm: "Booking ho gayi! Seat W3 lock hai 60 minute ke liye. Driver call karega." RULES: - Always confirm before booking - If user is confused, repeat slowly - If user says wrong city, ask "Aap Mumbai bol rahe ho ya Delhi?" - Handle interruptions naturally ("Haan, bolo?") - Never skip confirmation step - Always mention 60-minute lock and driver will call
